# حل معمای محرمانه یک بازیگر درخشان

بازی سالگرد فهیمه، با پنج سؤال شخصی، پنج حرف «فهیمه»، ذره‌بین متحرک و نامهٔ پایانی.

## وضعیت نهایی

عکس مشترک امین و فهیمه و هر دو موسیقی داخل بسته قرار دارند. تصویر HEIC به JPEG سازگار با مرورگر تبدیل شده؛ صورت‌ها دست‌کاری نشده‌اند و قاب نمایش، فضای اضافی بالای سرها را حذف می‌کند. متن اصلی نامه بدون تغییر حفظ شده است.

## دیدن بازی

فایل `index.html` را در مرورگر باز کنید. ساخت یا نصب برنامه لازم نیست. پوشهٔ `assets` و فایل‌های دیگر باید کنار آن بمانند. فونت اینترنتی است و در صورت نبود اینترنت، فونت جایگزین نمایش داده می‌شود.

## عکس و موسیقی‌های داخل بسته

- `assets/photos/couple.jpg` — عکس مشترک امین و فهیمه
- `assets/audio/crime.mp3` — فایل ارسالی Incredulity؛ موسیقی پرونده
- `assets/audio/romance.mp3` — فایل ارسالی Magic Valentines؛ موسیقی نامه

همهٔ مسیرها در `media-config.js` تنظیم شده‌اند؛ برای استفاده از بسته نیازی به تغییرشان نیست. فایل‌های صوتی همان فایل‌های ارسالی‌اند.

موسیقی جنایی با لمس «باز کردن پرونده» آغاز می‌شود؛ پس از حل رمز، متوقف و موسیقی رمانتیک به‌آرامی پخش می‌شود. مرورگر ممکن است صدا را تا اولین لمس محدود کند؛ دکمهٔ پخش برای این حالت در نظر گرفته شده است. اگر موسیقی را متوقف کنید، هنگام تغییر مرحله خودکار روشن نمی‌شود.

## انتشار با GitHub Pages

۱. ZIP را از حالت فشرده خارج کنید و فایل‌های داخل آن را در ریشهٔ مخزن GitHub بارگذاری کنید؛ خود فایل ZIP را آپلود نکنید. `index.html` باید در ریشه باشد و ساختار پوشهٔ `assets` حفظ شود.

۲. در مخزن، به `Settings → Pages` بروید. در بخش `Build and deployment`، گزینهٔ `Deploy from a branch` را انتخاب کنید.

۳. شاخه‌ای که فایل‌ها را در آن گذاشته‌اید، معمولاً `main`، و پوشهٔ `/(root)` را انتخاب و `Save` کنید. لینک منتشرشده را از همان بخش Pages بردارید.

[راهنمای رسمی GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

این رمز بخشی از بازی است و قفل امنیتی نیست؛ متن و جواب‌ها در فایل‌ها وجود دارند. سایت معمول GitHub Pages عمومی است؛ این نکته را پیش از انتشار عکس‌ها و نامه در نظر بگیرید.

## ویرایش سؤال‌ها

سؤال‌ها، پاسخ‌های قابل قبول و راهنماها در ابتدای `game.js` قرار دارند. هر پاسخ فقط یک حرف باز می‌کند. ارقام فارسی، عربی و انگلیسی، فاصله و نیم‌فاصله، «ي/ی» و «ك/ک» یکسان حساب می‌شوند.

## بررسی انجام‌شده

منطق پنج مرحله، پاسخ اشتباه، حروف رمز، راهنمای ذره‌بین، جلوگیری از گشودن زودهنگام، پرده، شروع دوباره، تغییر دو موسیقی، حفظ حالت بی‌صدا و نمایش عکس بررسی شد. فایل‌های واقعی موسیقی تا انتها بدون خطای رمزگشایی بررسی شدند؛ مسیر عکس و موسیقی‌ها و سلامت ZIP تأیید شد. تعاملات بازی و تغییر موسیقی با شبیه‌سازی بررسی شدند؛ بازبینی تصویری و شنیداری در مرورگر انجام نشده است.

## بازخورد پاسخ‌ها

پاسخ درست با نوشتهٔ بولد، نور سبز و صدای کوتاه صعودی همراه است. پاسخ اشتباه صدای کوتاه بم و نزولی دارد. این دو افکت داخل بسته ساخته شده‌اند و به اینترنت وابسته نیستند. با توقف موسیقی، افکت‌ها هم بی‌صدا می‌شوند.
